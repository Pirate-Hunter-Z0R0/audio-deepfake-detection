1. System-level design

Audio Deepfake Detection System has two kinds of users. The researcher runs the scripts that prepare data, train models and test them. The end user uploads an audio clip on the website and reads the result.

2. Module M1: Data Preparation

Responsibility: download the dataset, clean every clip, and convert each clip into a 78-number feature vector, with a held-out 20% test split.

D1 -->|"raw clips"| P2

P3 -->|"78-number vectors, labels, test split"| D3
